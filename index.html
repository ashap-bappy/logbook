          Sync — private GitHub repo

          Your logbook is stored as one JSON file in a repo you own. Every device that has the token sees the same data, and you get a full edit history for free.

          1. Create a private repo — logbook-data will do. Keep it separate from the repo hosting this page.
          2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
          3. Repository access: Only select repositories → pick that one repo.
          4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
          5. Set an expiry you'll actually renew, generate, and paste it below.

          This token can read and write that one repo, and it is kept in this browser. Revoke it on GitHub if you lose the device.
